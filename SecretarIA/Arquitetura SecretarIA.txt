# Roadmap corrigido — Secretária IA manual (sem inicialização automática)

Objetivo:
Você executa o script **somente quando precisar** (ex.: uma vez por dia ou quando receber muitos e-mails).

Tempo total: **4 a 6 semanas**, mantendo leve para sua rotina de faculdade.

---

## Fase 1 — Extrator manual de prazos (Semana 1)

Meta:
Criar um script que roda **apenas quando você executar**.

Fluxo:

1. Você copia um texto (de e-mail ou site)
2. Executa o script
3. O programa:

   * lê o texto copiado
   * detecta datas automaticamente

Bibliotecas:

* pyautogui
* pyperclip
* dateparser

Aqui você já resolve o problema básico.

---

## Fase 2 — Leitura manual de e-mails (Semana 2)

Meta:
Quando quiser, rodar o script para verificar novos prazos.

Fluxo:

1. Executa o script
2. Ele:

   * acessa sua caixa de entrada
   * filtra palavras como:

	* prazo
	* inscrição
	* edital
	* atividade
	* até
	* deadline
	* entrega
	* vagas
	* edital
	* canditat

Bibliotecas:

* imap-tools
* email

Nada roda automaticamente.

---

## Fase 3 — IA local interpretando eventos (Semana 3)

Instalar:

* **Ollama**
* modelo leve (3B)

Meta:
Transformar textos em eventos estruturados.

Biblioteca:

* requests

Exemplo de resultado:

* Evento
* Data
* Hora
* Observação

---

## Fase 4 — Criar eventos de calendário (Semana 4)

Meta:
Gerar automaticamente eventos quando você rodar o script.

Biblioteca:

* ics

Depois você importa automaticamente no:

* **Google Calendar**

Assim o celular recebe notificação normal.

---

## Fase 5 — Criar botão manual para executar (Semana 5)

Aqui está a correção principal.

Você NÃO vai automatizar o Windows.

Em vez disso:

* criar um atalho do script na área de trabalho
  ou
* criar um pequeno menu no terminal:

```
1 - Verificar novos prazos
2 - Ler emails
3 - Atualizar calendário
```

Assim você executa só quando quiser.

---

# Arquitetura final (manual e leve)

```
Você executa o script
        ↓
Script lê textos/emails
        ↓
IA local interpreta
        ↓
Eventos são criados
        ↓
Celular recebe notificação
```

---

# Sobre o modelo 3B (confirmando)

Para seu caso específico:

* lembretes
* prazos
* datas
* organização acadêmica

**Sim, um modelo 3B dá conta.**

Ele só não seria suficiente para:

* pesquisas complexas
* textos muito grandes
* análises profundas

Mas para “secretária pessoal”, funciona bem.
